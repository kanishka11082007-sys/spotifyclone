# Spotify Clone 🎵

A responsive Spotify-inspired music player built using **HTML, CSS, and JavaScript**.

This project is my first frontend development project, created to practice building a real-world web interface and adding interactive functionality using JavaScript.

## ✨ Features

* 🎵 Play and pause songs
* ⏭️ Next and previous song controls
* 🔀 Dynamic song loading
* 🎚️ Music progress/seek bar
* 🔊 Custom volume control
* 🔇 Mute and unmute
* 📱 Responsive layout for different screen sizes
* 🍔 Responsive hamburger menu
* ❌ Sidebar close button
* 🌑 Mobile overlay for the sidebar
* 🎶 Song information displayed in the playbar
* ▶️ Automatically plays the next song

## 🛠️ Technologies Used

* **HTML5** — Structure of the website
* **CSS3** — Styling, Flexbox, responsive design and media queries
* **JavaScript** — Music playback, DOM manipulation and event handling

## 🎯 What I Learned

While building this project, I practiced:

* Creating layouts with **Flexbox**
* Making websites responsive using **CSS media queries**
* Working with the **DOM**
* Handling mouse and click events
* Using JavaScript with the **HTML Audio API**
* Creating custom seekbars
* Managing audio volume and mute state
* Dynamically creating and displaying song elements
* Building a responsive sidebar and hamburger menu
* Debugging JavaScript and CSS issues

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project in VS Code.
3. Run the project using a local server such as **Live Server**.
4. Open the website in your browser.
5. Choose a song and start playing 🎵
